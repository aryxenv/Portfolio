# Data Processing & Analysis (YP0873)

## Course Overview & Academic Context

`Data Processing & Analysis` (Course Code: `YP0873`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y1Sem2`**.
- **Credit Weight**: **3 ECTS Credits**.
- **Official Examination Result**: **10/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y1Sem2 > DataProcessingAndAnalysis`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Data Processing & Analysis introduces programmatic data manipulation and exploratory data analysis (EDA) using the standard Python data science ecosystem. It bridges raw tabular inputs with structured analytical pipelines.

## Core Curriculum & Theoretical Foundations

Theoretical concepts include vectorized computing, NumPy array manipulation, Pandas Series and DataFrame architectures, hierarchical indexing, missing data handling strategies (deletion, mean/median imputation, forward fill), data type coercion, aggregation pipelines (`groupby`, `agg`), and basic descriptive statistical metrics (central tendency, dispersion, interquartile ranges).

## Practical Lab Work & Hands-On Projects

Lab work was conducted via interactive Jupyter Notebooks (`Les 1.ipynb` through `Les 11 Notebook.ipynb`). Students parsed, cleaned, and explored real tabular datasets including the Melbourne housing market dataset (`melb-data_exercise.ipynb`), filtering complex row criteria, engineering transformed features, resolving anomalous data entries, and aggregating multi-level operational metrics.

## Folder Structure & Studied Materials

The course materials, assignments, codebases, and student deliverables are systematically archived in the university cloud storage directory under `OneDrive - Thomas More/Y1Sem2/DataProcessingAndAnalysis`. The preserved folder hierarchy includes:

- **`DPA1 - DPA3`**: NumPy array basics, Pandas DataFrame creation, indexing, slicing, and attribute selection.
- **`DPA4 - DPA6`**: Data cleaning protocols, identifying and imputing missing data (`NaN`), data filtering, and outlier detection.
- **`DPA7 - DPA9`**: Data transformations, multi-column groupby operations, aggregations, and merging disparate tabular sources.
- **`DPA10 - DPA11`**: Comprehensive exploratory data analysis (EDA) pipelines on real estate datasets and end-of-semester assignment notebooks.

All code assets and technical reports reflect rigorous conceptual engineering, maintained without superfluous code dumps to preserve high-level semantic clarity.

## Key Competencies & Learning Outcomes

Competence in utilizing Python, Pandas, and NumPy for tabular data wrangling, missing data remediation, feature transformation, and exploratory statistical analysis.
