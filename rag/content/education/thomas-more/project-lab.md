# Project Lab (YB1402)

## Course Overview & Academic Context

`Project Lab` (Course Code: `YB1402`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y2Sem2`**.
- **Credit Weight**: **3 ECTS Credits**.
- **Official Examination Result**: **15/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y2Sem2 > ProjectLab`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Project Lab provides an authentic simulation of an Agile development team, requiring students to collaborate on a multi-tier e-business platform utilizing Test-Driven Development (TDD) and iterative release cycles.

## Core Curriculum & Theoretical Foundations

Theoretical modules encompass Scrum framework ceremonies (sprint planning, daily standups, sprint reviews, retrospectives), Test-Driven Development (Red-Green-Refactor cycle), unit testing best practices, database versioning and schema migrations, and collaborative Git branching strategies.

## Practical Lab Work & Hands-On Projects

Students engineered the **Sandy** e-business platform (`Sandy/plan.docx`, `Sandy/e-business lab.pptx`). The project required authoring relational database schemas and automated SQL migration updates (`sandydb_latest.sql`, `updates.sql`, `update_addresses.sql`), writing automated test suites, implementing feature user stories, and presenting sprint deliverables to client evaluators.

## Folder Structure & Studied Materials

The course materials, assignments, codebases, and student deliverables are systematically archived in the university cloud storage directory under `OneDrive - Thomas More/Y2Sem2/ProjectLab`. The preserved folder hierarchy includes:

- **`TDD Foundations`**: Test-Driven Development methodology lectures, writing failing unit tests, and the Red-Green-Refactor loop.
- **`Sandy Project Architecture`**: Requirements engineering, sprint backlog formulation, relational schema modeling, and dummy data generation.
- **`Sprint Execution & Database Migrations`**: Iterative feature delivery, SQL database migrations, test coverage verification, and team project presentation.

All code assets and technical reports reflect rigorous conceptual engineering, maintained without superfluous code dumps to preserve high-level semantic clarity.

## Key Competencies & Learning Outcomes

Working within Agile Scrum sprints, practicing Test-Driven Development (TDD), managing relational database migrations in production codebases, and team code collaboration.
