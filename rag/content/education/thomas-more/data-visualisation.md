# Data Visualisation (YP0840)

## Course Overview & Academic Context

`Data Visualisation` (Course Code: `YP0840`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y1Sem2`**.
- **Credit Weight**: **3 ECTS Credits**.
- **Official Examination Result**: **12/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y1Sem2 > DataVisualisation`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Data Visualisation equips students with the technical and aesthetic skills required to transform raw enterprise data into intuitive, actionable interactive dashboards using Microsoft Power BI.

## Core Curriculum & Theoretical Foundations

The course explores visual perception theories (Gestalt principles, pre-attentive attributes, color theory, cognitive load reduction), dimensional data modeling (fact tables, dimension tables, star and snowflake schemas), Data Analysis Expressions (DAX) syntax and evaluation context (row context vs. filter context), and Power Query M ETL transformations.

## Practical Lab Work & Hands-On Projects

Hands-on labs encompassed end-to-end dashboard builds in Power BI Desktop (`.pbix`). Exercises included data transformations with Power Query (appending, merging, unpivoting), modeling the AdventureWorks enterprise database, date dimension table creation, and DAX calculations. The major deliverable was an interactive Formula 1 analytics dashboard (`f1dataPowerBI_A08.pbix`) synthesizing race telemetry, driver performance, and team standings.

## Folder Structure & Studied Materials

The course materials, assignments, codebases, and student deliverables are systematically archived in the university cloud storage directory under `OneDrive - Thomas More/Y1Sem2/DataVisualisation`. The preserved folder hierarchy includes:

- **`DV1 - DV3`**: Power BI desktop introduction, Power Query ETL, appending and merging data tables, and foundational chart selection.
- **`DV4 - DV5`**: Dimensional modeling, relationship cardinality (1-to-many, many-to-many), and DAX measures (CALCULATE, RELATED, SUMX).
- **`DV6 - DV7`**: Date hierarchies, time-intelligence DAX functions, UI layout principles, and interactive filter/slicer configurations.
- **`DataProject_A08`**: Capstone Formula 1 visual analytics group project, executive reporting, and dashboard presentation.

All code assets and technical reports reflect rigorous conceptual engineering, maintained without superfluous code dumps to preserve high-level semantic clarity.

## Key Competencies & Learning Outcomes

Proficiency in Microsoft Power BI, star-schema data modeling, authoring DAX calculations, building interactive executive reporting dashboards, and applying visual design best practices.
