# Information Security Fundamentals (YP0874)

## Course Overview & Academic Context

`Information Security Fundamentals` (Course Code: `YP0874`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y1Sem2`**.
- **Credit Weight**: **3 ECTS Credits**.
- **Official Examination Result**: **14/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y1Sem2 > InformationSecurityFundamentals`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Information Security Fundamentals introduces the core tenets of information security and defense-in-depth across computing environments. It analyzes security threats from both technical network vectors and human organizational factors.

## Core Curriculum & Theoretical Foundations

Theoretical concepts include the CIA Triad (Confidentiality, Integrity, Availability), non-repudiation, threat landscapes (malware, phishing, ransomware, man-in-the-middle attacks), symmetric vs. asymmetric encryption (AES, RSA), hashing algorithms (SHA-256) and message integrity, public key infrastructure (PKI), digital signatures, authentication factors, and VPN tunneling protocols (IPsec, OpenVPN, WireGuard).

## Practical Lab Work & Hands-On Projects

Practical work included network security analysis, evaluating secure communication channels, configuring virtual private network tunnels, and authoring technical documentation such as the VPN implementation script and security defense review (`VPNscript.docx`).

The course materials, assignments, codebases, and student deliverables are systematically archived in the university cloud storage directory under `OneDrive - Thomas More/Y1Sem2/InformationSecurityFundamentals`. The preserved folder hierarchy includes:

## Key Competencies & Learning Outcomes

Understanding of fundamental cybersecurity architectures, encryption protocols, secure communication channel setup, risk assessment, and identity authentication mechanisms.
