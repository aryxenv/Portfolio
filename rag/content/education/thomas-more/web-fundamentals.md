# Web Fundamentals (YP0602)

## Course Overview & Academic Context

`Web Fundamentals` (Course Code: `YP0602`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y1Sem1`**.
- **Credit Weight**: **6 ECTS Credits**.
- **Official Examination Result**: **18/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y1Sem1 > WebFundamentals`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Web Fundamentals introduces the core building blocks of the World Wide Web. The course teaches students how to construct modern, accessible, and responsive user interfaces from scratch using clean semantic markup, advanced CSS layout techniques, and dynamic JavaScript behavior.

## Core Curriculum & Theoretical Foundations

Theoretical modules cover the client-server web architecture, HTTP request-response lifecycle, W3C web standards, HTML5 semantic element hierarchy, Document Object Model (DOM) tree representations, CSS Box Model, CSS specificity rules, Flexbox axes and alignment, CSS Grid layout patterns, responsive viewport media queries, JavaScript event-driven paradigms, and asynchronous browser events.

## Practical Lab Work & Hands-On Projects

Practical lab exercises spanned responsive portfolio interfaces, interactive DOM calculators (`WebFundamentalsCalc`), event-driven browser mini-games (`WebFundamentalsFarm`, `WebFundamentalsEmoji`), and dynamic web forms. Coursework culminated in a comprehensive practical examination building a fully responsive, interactive web application within strict performance and accessibility standards.

## Folder Structure & Studied Materials

The course materials, assignments, codebases, and student deliverables are systematically archived in the university cloud storage directory under `OneDrive - Thomas More/Y1Sem1/WebFundamentals`. The preserved folder hierarchy includes:

- **`01WebFundamentals - 03WebFundamentals`**: Semantic HTML5 architecture, structural page layout, text formatting, hyperlinks, media assets, and forms.
- **`04WebFundamentals - 06WebFundamentals`**: CSS3 styling, Box Model mechanics, CSS Flexbox layouts, CSS Grid systems, and responsive media queries.
- **`05WebFundamentalsJS & Components`**: JavaScript language fundamentals, DOM element selection, dynamic attribute manipulation, and event listeners.
- **`Exam2023Web & Advanced Labs`**: Integrated responsive client-side applications combining HTML5, advanced CSS styling, and interactive JavaScript functionality.

All code assets and technical reports reflect rigorous conceptual engineering, maintained without superfluous code dumps to preserve high-level semantic clarity.

## Key Competencies & Learning Outcomes

Ability to craft responsive, accessible web interfaces adhering to modern web standards, build complex multi-column layouts with Flexbox/Grid, manipulate the DOM dynamically with vanilla JavaScript, and debug client-side web assets.
