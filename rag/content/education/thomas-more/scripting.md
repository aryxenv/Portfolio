# Scripting (YP0871)

## Course Overview & Academic Context

`Scripting` (Course Code: `YP0871`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y1Sem2`**.
- **Credit Weight**: **6 ECTS Credits**.
- **Official Examination Result**: **13/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y1Sem2 > Scripting`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Scripting expands programming capabilities into versatile Python automation, teaching students how to glue systems together, interact with file systems, consume remote web services, and automate routine administrative data pipelines.

## Core Curriculum & Theoretical Foundations

The course covers Python data structures (lists, tuples, sets, dictionaries, comprehensions), modular packaging, file I/O streams, structured text and serialization formats (CSV, JSON), HTTP requests and REST architecture, regex pattern matching, Python database access (SQLite/SQL), and interactive notebook workflows.

## Practical Lab Work & Hands-On Projects

Students developed automated scripts across interactive Jupyter Notebooks and standalone `.py` modules. Projects included building REST API consumption utilities (`API.ipynb`), processing nested JSON data models (`books.json`, `activities.json`), database-driven Python pipelines (`databaseWeek10.ipynb`), and building utility functions for data extraction and transformation under time-constrained exam conditions.

## Folder Structure & Studied Materials

The course materials, assignments, codebases, and student deliverables are systematically archived in the university cloud storage directory under `OneDrive - Thomas More/Y1Sem2/Scripting`. The preserved folder hierarchy includes:

- **`S1 - S4`**: Python fundamentals review, complex data structures, list/dict comprehensions, and custom function modularity.
- **`S5 - S7`**: File system operations, text stream processing, CSV parsing, and JSON serialization/deserialization.
- **`S8 - S10`**: HTTP requests library, REST API querying, error handling, and structured data extraction.
- **`S11 & Assignments/Exam`**: Database integration via Python, SQLite operations, and integrated automation challenge examinations.

All code assets and technical reports reflect rigorous conceptual engineering, maintained without superfluous code dumps to preserve high-level semantic clarity.

## Key Competencies & Learning Outcomes

Versatility in Python scripting, programmatic automation of data workflows, robust JSON/CSV processing, REST API querying, and rapid prototyping of system integration tools.
