# Computer Toolkit (YP0846)

## Course Overview & Academic Context

`Computer Toolkit` (Course Code: `YP0846`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y1Sem1`**.
- **Credit Weight**: **3 ECTS Credits**.
- **Official Examination Result**: **Pass** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y1Sem1 > ComputerToolkit`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Computer Toolkit provides foundational technical literacy across computer hardware, operating system virtualization, remote systems administration, and administrative scripting. It establishes the practical infrastructure baseline required for advanced data science and cloud engineering.

## Core Curriculum & Theoretical Foundations

Theoretical concepts include computer system architectures (motherboards, CPUs, memory hierarchies, storage buses, and peripheral interfaces), hypervisor architectures (Type 1 bare-metal vs. Type 2 hosted virtualization), terminal command-line interaction, cryptographic fundamentals of Secure Shell (asymmetric key pairs, host verification, tunneling), and HTTP client-server communication using RESTful APIs.

## Practical Lab Work & Hands-On Projects

Practical deliverables included a complete documented computer component build specification, provisioning and configuring guest virtual machines using virtualization hypervisors, authoring automation scripts in PowerShell to parse system metrics, establishing secure remote administration tunnels via SSH, and formulating technical reports querying external REST APIs with structured JSON output parsing.

## Key Competencies & Learning Outcomes

Demonstrated competence in hardware component assembly, hypervisor-based VM management, administrative terminal fluency in PowerShell, secure cryptographic shell connectivity, and programmatic consumption of web APIs.
