# DevOps (YB1461)

## Course Overview & Academic Context

`DevOps` (Course Code: `YB1461`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y3Sem1`**.
- **Credit Weight**: **3 ECTS Credits**.
- **Official Examination Result**: **18/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y3Sem1 > DevOps`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

DevOps teaches modern software delivery lifecycle methodologies, bridging software engineering with infrastructure operations through containerization, automated testing, and CI/CD pipelines.

## Core Curriculum & Theoretical Foundations

The curriculum covers DevOps cultural pillars (CALMS framework), containerization principles (namespaces, cgroups, image layering, Docker daemon), container networking and persistent volumes, Continuous Integration and Continuous Delivery (CI/CD) pipeline design, GitHub Actions workflows (triggers, jobs, runners, secrets), automated test execution, and Infrastructure as Code (IaC) principles.

## Practical Lab Work & Hands-On Projects

Practical coursework centered on containerizing and automating the **Taskflow** multi-tier web application (`Taskflow/`). Students wrote multi-stage Dockerfiles, authored GitHub Actions workflow pipelines automating linting, testing, and container build steps, and defended their deployment pipelines in a rigorous oral examination (`ORAL_EXAMINATION.md`, `EXAM_INSTRUCTIONS.md`).

## Folder Structure & Studied Materials

The course materials, assignments, codebases, and student deliverables are systematically archived in the university cloud storage directory under `OneDrive - Thomas More/Y3Sem1/DevOps`. The preserved folder hierarchy includes:

- **`Week 1 - Week 4`**: DevOps principles, Linux terminal operations, containerization mechanics, and writing optimized Dockerfiles.
- **`Week 5 - Week 8`**: Container networking, multi-container orchestration with Docker Compose, and persistent data volumes.
- **`Week 9 - Week 11`**: GitHub Actions CI/CD workflows, automated testing pipelines, secret management, and deployment automation.
- **`Taskflow Exam Project`**: Complete multi-tier application containerization, automated CI/CD pipeline configuration, and oral exam defense.

All code assets and technical reports reflect rigorous conceptual engineering, maintained without superfluous code dumps to preserve high-level semantic clarity.

## Key Competencies & Learning Outcomes

High proficiency in Docker containerization, authoring robust GitHub Actions CI/CD pipelines, multi-container orchestration, and defending automated deployment architectures in technical oral exams.
