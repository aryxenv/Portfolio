# Inspiration Lab (YP0597)

## Course Overview & Academic Context

`Inspiration Lab` (Course Code: `YP0597`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y1Sem2`**.
- **Credit Weight**: **3 ECTS Credits**.
- **Official Examination Result**: **19/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y1Sem2 > InspirationLab`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Inspiration Lab is an integrative, multidisciplinary lab where students apply their cumulative programming, database, and UI design skills to architect and build a complete software product from initial conception to production delivery.

## Core Curriculum & Theoretical Foundations

Key concepts include desktop UI architectures using Windows Presentation Foundation (WPF) and XAML, Model-View-ViewModel (MVVM) software patterns, database connectivity and ADO.NET/ORM pipelines, cryptographic password hashing, role-based user access management, and modular software project structuring.

## Practical Lab Work & Hands-On Projects

The primary course achievement was the design and implementation of **Project Actifuse**—a comprehensive C# WPF desktop fitness and activity generation application. The project featured an integrated SQL relational backend (`actifuse.sql`, `hospital.sql`), secure user authentication with password reset workflows (`Authentication.xaml.cs`, `ForgotPasswordStep2.xaml.cs`), administrative dashboard management (`AdminDashboard.xaml.cs`), dynamic workout generation algorithms, and activity logging history.

## Folder Structure & Studied Materials

The course materials, assignments, codebases, and student deliverables are systematically archived in the university cloud storage directory under `OneDrive - Thomas More/Y1Sem2/InspirationLab`. The preserved folder hierarchy includes:

- **`IL1 - IL3`**: Project ideation, requirements definition, architecture blueprinting, and relational database schema modeling.
- **`IL4 - IL6`**: WPF UI design in XAML, event-driven controller development, and database integration.
- **`ProjectActifuse`**: End-to-end desktop software delivery: authentication, admin controls, dynamic workout generator, and final codebase.

All code assets and technical reports reflect rigorous conceptual engineering, maintained without superfluous code dumps to preserve high-level semantic clarity.

## Key Competencies & Learning Outcomes

End-to-end desktop software architecture in C# and WPF, relational database integration, building multi-view user interfaces with XAML, role-based access control implementation, and team code collaboration.
