Web Programming covers modern full-stack web development, bridging relational database backends, server-side business logic, Object-Relational Mapping (ORM), and reactive client-side interfaces. Aryan achieved a **perfect score of 20/20** in this course.

## Core Curriculum & Theoretical Foundations

The curriculum examines client-server web architectures, RESTful API design principles, Object-Relational Mapping (ORM) design patterns, schema migrations, asynchronous event handling, HTTP authentication and session state, data validation, and responsive component-driven UI architecture.

## Practical Lab Work & Hands-On Projects

The central course achievement was the complete engineering of **Airbnb-for-Campers** (`Airbnb-for-campers/` and `Airbnb-for-campers-local/`). Aryan designed the relational database schema (`airbnb_for_campers.sql`), generated realistic test data (`airbnb_for_campers_dummy_data.sql`), configured the Prisma ORM layer (`prisma_setup.md`), and engineered the RESTful API routes (`api_structure.md`) connecting property listings, camper availability, booking transactions, and user profiles.
