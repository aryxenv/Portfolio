# Network Fundamentals (YB1404)

## Course Overview & Academic Context

`Network Fundamentals` (Course Code: `YB1404`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y2Sem1`**.
- **Credit Weight**: **3 ECTS Credits**.
- **Official Examination Result**: **15/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y2Sem1 > NetworkFundamentals`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Network Fundamentals teaches the principles of computer networking, transmission protocols, and enterprise infrastructure design, emphasizing practical hands-on simulation in Cisco Packet Tracer.

## Core Curriculum & Theoretical Foundations

The course covers the 7-layer OSI reference model and the 4-layer TCP/IP protocol suite, physical transmission media, Ethernet framing, MAC addressing, IPv4 classless addressing (CIDR) and VLSM subnetting, IPv6 architecture, Address Resolution Protocol (ARP), transport layer protocols (TCP handshakes, flow control vs. UDP datagrams), network segmentation via Virtual LANs (VLANs), Inter-VLAN routing, and application protocols (DNS, DHCP, HTTP, SSH).

## Practical Lab Work & Hands-On Projects

Labs were designed and executed in Cisco Packet Tracer (`.pkt` topologies). Students configured router interfaces, switch ports, trunking protocols (802.1Q), and VLAN segmentations (`vlanPacketTracers.pkt`). Practical deliverables included three comprehensive network configuration assignments (`networkAssignment1.pkt`, `assignment2packettracer.pkt`, and associated technical verification reports), verifying end-to-end IP connectivity and security segmentation.

## Folder Structure & Studied Materials

The course materials, assignments, codebases, and student deliverables are systematically archived in the university cloud storage directory under `OneDrive - Thomas More/Y2Sem1/NetworkFundamentals`. The preserved folder hierarchy includes:

- **`Week 1 - Week 2`**: Network models and topologies, OSI vs. TCP/IP, physical media, and Cisco Packet Tracer environment introduction.
- **`Week 3 - Week 4`**: Internet Protocol Suite, IPv4 addressing, binary conversions, and Variable Length Subnet Masking (VLSM).
- **`Week 5 - Week 6`**: Switching mechanics, MAC address tables, VLAN creation, trunk ports, and network traffic segmentation.
- **`Week 7 - Week 8`**: Routing concepts, static routes, default gateways, Inter-VLAN routing, DHCP server configuration, and final verification.

All code assets and technical reports reflect rigorous conceptual engineering, maintained without superfluous code dumps to preserve high-level semantic clarity.

## Key Competencies & Learning Outcomes

Proficiency in enterprise network design, configuring Cisco routers and switches in Packet Tracer, calculating complex IPv4 subnet allocations, implementing VLAN network segmentation, and troubleshooting IP connectivity.
