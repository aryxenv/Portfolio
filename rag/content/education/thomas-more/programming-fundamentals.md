# Programming Fundamentals (YP0921)

## Course Overview & Academic Context

`Programming Fundamentals` (Course Code: `YP0921`) is a mandatory course unit in the Bachelor of International Business Management (Data Science, Protection & Security) curriculum at Thomas More University of Applied Sciences, Mechelen Campus. 

- **Academic Period**: Completed during academic semester **`Y1Sem1`**.
- **Credit Weight**: **9 ECTS Credits**.
- **Official Examination Result**: **19/20** (Pass with credit obtained).
- **Academic Archive Location**: `OneDrive - Thomas More > Y1Sem1 > ProgrammingFundamentals`.
- **Authoritative Source**: Confirmed in official Thomas More Transcript of Records (Code: `09C6AF65875C4383AC5A581FFEFEB9B0`).

Programming Fundamentals is an intensive 9-ECTS engineering course forming the primary coding foundation of the curriculum. Taught in C# on .NET Core, it develops deep algorithmic fluency, programmatic thinking, and disciplined code structure.

## Core Curriculum & Theoretical Foundations

Theoretical concepts encompass memory management (stack vs. heap allocation, value types vs. reference types), strongly typed type systems, conditional logic, iterative control structures, array manipulation, string algorithms, method modularization, parameter passing (`ref`, `out`), collection frameworks (`List<T>`, `Dictionary<TKey, TValue>`), exception handling, and core object-oriented principles including encapsulation, access modifiers, constructors, properties, and class design.

## Practical Lab Work & Hands-On Projects

Students engineered hundreds of algorithmic console applications covering mathematical sequences, text processing, array searching/sorting, data validation, and modular multi-class systems. Practical assignments emphasized clean coding conventions, robust input handling, unit test verification, and automated edge-case checking.

High fluency in C# programming, disciplined algorithmic logic, mastery of memory types and data structures, clean object-oriented class architecture, and defensive programming practices.
