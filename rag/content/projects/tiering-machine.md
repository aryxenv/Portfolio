# Tiering Machine - Dystopian Social Credit Simulation with AI Judge

## Project Overview
Automated decision-making systems and algorithmic governance are increasingly deployed across finance, criminal justice, and civic administration. **Tiering Machine** is a provocative, interactive web simulation created by Aryan Shah that immerses users in a dystopian **Social Credit System** where an omniscient, bureaucratic **AI Judge** continuously surveils, scores, and categorizes citizens into social tiers.

The application serves as both an entertaining interactive game and a philosophical thought experiment on the ethical perils of algorithmic bias, automated surveillance, and social stratification.

## Core Features & Simulation Mechanics

### 1. Dystopian Surveillance & Cyberpunk Interface
- **Brutalist Visual Design**: Styled with a dark cyberpunk aesthetic featuring high-contrast HUD monitors, scanline overlays, neon status indicators, and terminal typography (`Share Tech Mono`, `Roboto`).
- **Surveillance Feed Simulation**: Simulates automated citizen activity telemetry, displaying live infraction alerts, biometric status scans, and state propaganda bulletins.

### 2. The Algorithmic "AI Judge" Engine
- **Automated Incident Processing**: Users can submit infraction reports (e.g., *“Citizen consumed unapproved media during designated quiet hours”* or *“Citizen completed voluntary weekend community infrastructure repair”*).
- **Sentiment & Severity Adjudication**: The AI judge analyzes report text, categorizes infraction severity against strict state decrees, calculates point adjustments (e.g., `-75 Civic Points` or `+30 Compliance Merits`), and generates cold, bureaucratic algorithmic decrees justifying the penalty.
- **Dynamic Tier Recalibration**: Citizens are categorized into rigid social strata:
  - **Tier 1 (Apex Citizens)**: Unrestricted travel, luxury privileges, priority resource allocation.
  - **Tier 2 (Compliant Class)**: Standard permissions, monitored network access.
  - **Tier 3 (Probationary)**: Strict curfews, ration penalties, restricted movement.
  - **Tier 4 (Outcasts / Dissenters)**: Total civic rights suspension, scheduled re-education warnings.

### 3. Dynamic Citizen Registry & Real-Time Leaderboard
- **State Registry Table**: Displays a real-time updating database of monitored citizens, tracking historical infractions, cumulative compliance scores, and instantaneous tier elevations or demotions.
- **Interactive Citizen Profile Inspection**: Clicking any citizen reveals their surveillance dossier, recent flagged activities, and algorithmic risk assessments.

### 4. Technical Architecture
- **Frontend Stack**: Built with React and TypeScript, bundled with Vite for high frame-rate animations and snappy UI responsiveness.
- **State Management**: Reactive state stores handling concurrent event dispatching, score decay algorithms, and dynamic DOM updates.
